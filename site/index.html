FujiNet NFC reader: install the software

This page puts the software onto your reader (a D1 mini with an NFC module) over USB. You do not need to install anything on your computer.

Before you start

  • Use Chrome or Edge on a Windows, Mac or Linux computer. Firefox, Safari, phones and tablets cannot do this.
  • Plug the D1 mini into the computer with a USB data cable (some cables only charge). Many D1 minis need the free CH340 driver first; if the list in step 2 stays empty, install it and plug the reader in again.
  1. Click Install reader (English) below.
  2. Pick your D1 mini in the window that opens (often called “USB-SERIAL CH340”) and click Connect.
  3. You are asked whether to erase the device first. For a new reader, either answer works. If the reader already has your WiFi saved, Erase deletes that WiFi; leave it unticked to keep it.
  4. Wait until the installation is done (about a minute). Then enter the name and password of your home WiFi when asked.

This browser cannot install the software. Open this page in Chrome or Edge on a desktop or laptop computer. Firefox, Safari and phones do not work. Installing only works on a secure page (address starting with https://). Open this page with its https address instead.

After that, the reader shows its own web page in your home network. Follow the guide for the next steps: English · Deutsch.

FujiNet-NFC-Leser: Software aufspielen

Diese Seite spielt die Software über USB auf Deinen Leser (ein D1 mini mit NFC-Modul). Auf dem Computer musst Du nichts installieren.

Vorher

  • Nimm Chrome oder Edge auf einem Windows-, Mac- oder Linux-Computer. Firefox, Safari, Handys und Tablets können das nicht.
  • Stecke den D1 mini mit einem USB-Datenkabel an den Computer (manche Kabel laden nur). Viele D1 mini brauchen zuerst den kostenlosen CH340-Treiber; bleibt die Liste in Schritt 2 leer, installiere ihn und stecke den Leser neu an.
  1. Klicke unten auf Leser installieren (Deutsch).
  2. Wähle im Fenster Deinen D1 mini aus (oft „USB-SERIAL CH340“) und klicke auf Verbinden.
  3. Dann fragt das Fenster, ob das Gerät vorher gelöscht (Erase) werden soll. Bei einem neuen Leser geht beides. Hat der Leser Dein WLAN schon gespeichert, löscht Erase dieses WLAN; ohne Haken bleibt es erhalten.
  4. Warte, bis die Installation fertig ist (etwa eine Minute). Gib dann Namen und Passwort Deines WLANs ein, wenn danach gefragt wird.

Dieser Browser kann die Software nicht aufspielen. Öffne die Seite in Chrome oder Edge auf einem Desktop- oder Laptop-Computer. Firefox, Safari und Handys gehen nicht. Aufspielen geht nur auf einer gesicherten Seite (Adresse beginnt mit https://). Öffne diese Seite stattdessen mit ihrer https-Adresse.

Danach zeigt der Leser in Deinem Heimnetz eine eigene Webseite. Die nächsten Schritte stehen in der Anleitung: Deutsch · English.
