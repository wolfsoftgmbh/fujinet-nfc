# Contributing

Issues and pull requests are welcome, in English or German.

- **Bugs and ideas:** open an issue. For a bug, say which firmware image you use (English or German,
  version), what you did, and what the reader's web page showed under "Status" and "Last result".
- **Pull requests:** keep them small and about one thing. Run `make check` before you push; it must pass
  (ruff, mypy, a check for external resources, the host tests of `karte.h`, and the ESPHome configuration
  for both languages). `make test` runs the Python tests against the mock FujiNet. You need `uv` and `g++`;
  [firmware/README.md](firmware/README.md) has the details.
- **Texts:** the English and the German guide and interface texts must say the same. If you change one,
  change the other, or say in the pull request that you could not.
- **No external resources** in the flash page, the guide or the README: no CDN, fonts, trackers or images
  from other servers. `make check` looks for them.
- **Examples** use addresses like `192.168.0.x`; no real WiFi names, host names or passwords.
- The parts list in `docs/` is generated by `rechnungen/stueckliste.py`. Change the script, not the
  Markdown files.
